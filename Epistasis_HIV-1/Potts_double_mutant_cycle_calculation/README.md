#Code for Potts model scan of double mutant cycles

Code to calculate double mutant cycles using the Potts model. This code requires as input the Potts model on line 35 and a reference sequence (in the reduced 4-letter alphabet) on line 48.

The inferred Potts models for PR, RT, and IN from multiple sequence alignments derived from the Stanford HIV drug resistance database are provided in the data/models directory. For more details, please refer to the Materials and Methods section.
